# ATM Management System

A simple ATM Management System developed using C language.

## Features

- Check Account Balance
- Deposit Money
- Withdraw Money
- Change PIN
- Exit the program
- Invalid choice handling
- Insufficient balance handling
- PIN verification

## Language

- C

## Concepts Used

- Variables
- Data Types
- Input and Output
- If-Else
- Switch Case
- While Loop
- Functions
- Arithmetic Operators
- Conditional Statements

## How to Run

1. Compile the `atm.c` file using a C compiler.
2. Run the program.
3. Enter your PIN.
4. Select an option from the ATM menu.
5. Perform the required transaction.
6. Select Exit when finished.
